O que é um banco de dados?

Um banco de dados é uma coleção organizada de informações ou dados estruturados, geralmente armazenados eletronicamente em um sistema de computador. Um banco de dados é normalmente controlado por um sistema de gerenciamento de banco de dados (DBMS). Juntos, os dados e o DBMS, juntamente com os aplicativos associados, são referidos como um sistema de banco de dados, frequentemente abreviado para apenas banco de dados.
